# Privacy Policy

Last updated: 21 September 2026

Stanley House Nest is a private Home Assistant integration operated by one individual for their own household. It has no other users.

## What it accesses

With the account owner's explicit consent, this application uses Google's Smart Device Management API to read device information and live video streams from Google Nest cameras that the account owner owns.

## How that data is used

The data is used for one purpose only: to display the owner's own cameras inside the owner's own Home Assistant instance, which runs on hardware located in the owner's home.

## Storage

No Google user data is stored on any server operated by this application. Video is viewed live and is not recorded by this integration. Authentication tokens are stored locally on the owner's Home Assistant instance and nowhere else.

## Sharing

No Google user data is transferred, sold, shared with, or disclosed to any third party, for any purpose.

## Revoking access

The account owner can revoke this application's access at any time from their Google Account permissions page. Doing so immediately and permanently ends the application's access.

## Changes

Any changes to this policy will be published on this page.
